# spotify-ctrl-q-queue
- quick script to queue on spotify desktop with CTRL + Q

# INSTRUCTIONS
- navigate to directory through terminal, then run "swift run"
- hover over song you want to queue, then press CTRL + Q
- (make sure you are not hovering over the name of the song/artist or any hyperlinked content on the song)

# DISCLAIMER
- ONLY WORKS WITH YOUR OWN PLAYLISTS, and doesn't work on liked songs :(
